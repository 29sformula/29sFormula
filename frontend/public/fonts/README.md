# Custom Fonts Folder

Place your custom **Benn** font files in this folder.

To make the browser load the font successfully:
1. Save your custom font file as **`Benn-Regular.ttf`** (or `.woff2` / `.woff`).
2. Drop it directly into this folder: `/frontend/public/fonts/`.
3. The browser will automatically apply it as the brand title's typeface.
